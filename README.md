## 🎯 О проекте

**MathCore** — мобильное приложение для изучения и практики высшей математики. Решай задачи, читай теорию, сражайся с другими студентами в реальном времени и следи за своим прогрессом через XP-систему и рейтинги.

Приложение является Android-портом одноимённого веб-приложения, реализованным с нуля на Kotlin + Jetpack Compose.

## 🛠️ Технический стек

```
📱 UI          → Jetpack Compose + Material 3
🏗️ Архитектура → MVVM (ViewModel + StateFlow)
🌐 Backend     → Supabase (PostgreSQL + Auth + Storage + Realtime)
🔌 HTTP        → Ktor Client
🔄 Realtime    → WebSocket (Ktor + Supabase Realtime)
📦 Сериализация→ Kotlinx Serialization
💾 Локально    → DataStore Preferences
🖼️ Изображения → Coil Compose
📐 Формулы     → KaTeX (в WebView)
🔔 Async       → Kotlin Coroutines + Flow
```

## 🚀 Сборка

### Требования
- Android Studio Hedgehog или новее
- JDK 11+
- Android SDK 26+

### Запуск
```bash
git clone https://github.com/your-repo/MathCoreAndroid
cd MathCoreAndroid
./gradlew assembleDebug
```

APK будет в:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Переменные окружения
Суpabase конфиг находится в:
```
app/src/main/java/com/mathcore/app/data/repository/SupabaseClient.kt
```

## 📁 Структура проекта

```
app/src/main/
├── assets/questions/          # 21 JSON-файл с вопросами
├── java/com/mathcore/app/
│   ├── data/
│   │   ├── model/             # Profile, TestResult, LeaderboardEntry
│   │   ├── repository/        # AuthRepository, ResultsRepository
│   │   ├── local/             # PreferencesManager (DataStore)
│   │   ├── Question.kt        # Question, QuizConfig, QuizResult
│   │   └── TheoryData.kt      # Весь контент теории
│   ├── ui/
│   │   ├── auth/              # Вход / регистрация
│   │   ├── home/              # Главный экран + ежедневный вызов
│   │   ├── quiz/              # Экран теста + формулы
│   │   ├── duel/              # Дуэль в реальном времени
│   │   ├── profile/           # Профиль + статистика
│   │   ├── stats/             # Глобальный рейтинг
│   │   ├── theory/            # Теория с KaTeX
│   │   ├── exam/              # Экзаменационный режим
│   │   ├── mistakes/          # Работа над ошибками
│   │   └── search/            # Поиск пользователей
│   ├── viewmodel/             # QuizVM, AuthVM, DuelVM, ExamVM
│   └── util/
│       └── SoundManager.kt    # Синтез звуков через AudioTrack
└── MainActivity.kt            # Навигация + состояние приложения
```

Сложный вопрос верно → +30 XP

────────────────────────────────
Каждые 3000 XP       → новый уровень
